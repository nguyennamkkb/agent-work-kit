Đã kiểm

Mỗi nghề có định nghĩa “xong” riêng.

Việc lớn thì chia cho đội.

Chọn tầng rẻ nhất mà vẫn đủ. Chỉ leo khi có bằng chứng.

  • T0Agent chính1 đến 3 file
  • T1Subagent của harnessĐọc, khảo sát
  • T2Một worker OrcaMột module, chạy lâu
  • T3Engineer và testerNhiều module, cần test
  • T4Mỗi plan một leadTừ 2 plan cùng lúc
  • agent chính
  • lead của plan
  • worker
  • tester
  • subagent
  • worktree riêng

Leo tầng khi quá 3 file, 15 lần gọi công cụ, hoặc build đỏ hai lần.

  1. PlanQuyết định, thứ tự, tiêu chí xong.
  2. ViệcGhi rõ file sở hữu.
  3. GiaoChọn model, viết brief, mở worker.
  4. KiểmĐọc diff, kiểm sha.
  5. ĐóngQua cổng test. Bạn đồng ý mới merge.

Mở worker lần đầu, agent hỏi bạn trước.Cần Orca và git. Không có Orca vẫn chạy với một agent.

Mở một file là thấy cả đội.

Một file .desk/desk.html. Không cần server, tự làm mới mỗi 10 giây.

  • Đèn sức khoẻXanh, vàng, đỏ kèm lý do.
  • Cần bạnCâu hỏi, báo cáo, đề xuất chờ duyệt.
  • ĐộiAi làm gì, bao lâu.
  • Hiệu quả từng modelTỉ lệ thành công của từng model.

Hợp với công cụ bạn đang dùng.
