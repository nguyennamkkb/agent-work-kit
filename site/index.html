01 Cài đặt

Dán một dòng lệnh, rồi làm theo 6 bước

Mỗi bước nói rõ bạn gõ gì và nhìn thấy gì.

TERMINAL 
npx github:nguyennamkkb/agent-work-kit init --universal

Bấm Chép lệnh, quay lại terminal và dán.

Desk installed: + .desk/desk.json + .agentkit/... ... Ready.

Ba gói --universal / --ios / --designer (chi tiết ở Hỏi đáp) · Cần Node 18+, một terminal, thư mục dự án · Không cần tài khoản.

  1. 01

    Mở terminal đúng thư mục

    VS Code: Terminal → New Terminal. Không dùng VS Code thì gõ cd đường-dẫn-tới-dự-án — dấu nhắc kết thúc bằng tên thư mục là đúng.

  2. 02

    Dán và chạy lệnh cài

    Dùng nút Chép lệnh ở khung lệnh, dán vào terminal, nhấn Enter — terminal liệt kê file mới rồi hiện Ready.

  3. 03

    Kiểm tra ba file của bàn

    Gõ ls .desk (macOS) hoặc dir .desk (Windows) — thấy desk.json, DESK.md, desk.html.

  4. 04

    Mở bảng điều khiển

    Gõ open .desk/desk.html (macOS) hoặc start .desk\desk.html, hoặc bấm đúp file — dashboard mở ra, còn trống.

  5. 05

    Mở agent trong dự án

    Mở agent bạn dùng ngay trong thư mục dự án (xem mục 02) — hook mở phiên in một dòng: mục tiêu · việc đang làm · việc kế.

  6. 06

    Nói việc đầu tiên

    Gõ một câu bình thường, ví dụ Việc đầu tiên: lên kế hoạch cho buổi ra mắt. — việc xuất hiện ở doing, kèm điều kiện xong.

03 Cái bàn

Một việc đi qua những đâu?

Agent tự chuyển trạng thái. Bạn chỉ cần nói việc. Mỗi trạng thái một nghĩa rõ ràng.

Luồng chính

  1. inbox

    Ghi nhanh, chưa phân loại.

  2. todo

    Hàng chờ theo P0 → P3.

  3. doing

    Đang làm, một việc một lúc.

  4. review

    Đang kiểm kết quả.

  5. done ✓

    Xong, luôn kèm bằng chứng.

Ngoài luồng chính

  • waiting

    Chờ người, việc khác, hoặc tới hạn. Tự quay lại.

  • dropped

    Bỏ có lý do, lấy lại được.

  • failed

    Thất bại, kèm lý do.

  • P0gấp
  • P1nên làm
  • P2đợi được
  • P3có thì tốt

Nói “gấp” hoặc “quan trọng” là việc được nâng lên P0.

04 Bạn nói

Bạn nói gì, bàn làm nấy

Không cần học lệnh. Nói như đang trao đổi với đồng nghiệp. Agent tự ghi vào bàn.

“Làm màn hình đăng nhập.”→Thành việc doing, kèm điều kiện xong do agent suy ra.
“Gấp.” / “Quan trọng.”→Việc vừa nhắc lên P0 (thang ưu tiên ở mục 03).
“Để sau.” / “Tuần sau.”→Vào todo với ưu tiên thấp, không làm ngay.
“Chờ anh A gửi API.”→Sang waiting.
“Bỏ việc đó đi.”→Sang dropped, lưu nguyên lời bạn làm lý do. Lấy lại được.
“Nhớ: luôn build bằng scheme Lumen-Dev.”→Lưu vào bộ nhớ. Phiên sau vẫn còn.
“Sai rồi, đừng sửa file đó.”→Thành một bài học. Gặp lần hai, agent đề xuất cách sửa gốc.
“Chia việc cho đội làm song song.”→Việc được chia cho worker chạy song song (cần Orca, xem mục 07).

Dòng cuối là chế độ đội, cần Orca.

06 An toàn

Không có gì mất hẳn

Bàn được làm để bạn yên tâm. Việc lớn luôn hỏi trước, thao tác nhầm vẫn lùi được.

Hoàn tác 30 bước

desk undo lùi lại thao tác vừa rồi. Việc đã huỷ vẫn nằm trong archive.

Bỏ việc phải có lý do

drop bắt buộc nhập lý do. Lý do được giữ nguyên văn.

Việc lớn hỏi trước

Push, merge, deploy, xoá worktree: agent phải hỏi bạn.

Gỡ sạch khi muốn

remove trả mọi file về đúng từng byte; .desk/ được giữ trừ khi thêm --purge-desk.

Kit chỉ ghi trong thư mục dự án, không ghi vào home.

07 Tùy chọn

Khi việc lớn dần

Một agent là đủ cho hầu hết việc.

Việc đủ lớn, kit có thể chia cho nhiều agent chạy song song, mỗi agent một worktree riêng, và kiểm trước khi merge.

Phần này cần ứng dụng Orca. Không có Orca, bàn vẫn chạy đầy đủ với một agent. Worker đầu tiên của mỗi phiên cần bạn đồng ý một lần.

Cần Orca · tùy chọn 
lead   ── chia việc
 ├─ worker 1  worktree riêng
 ├─ worker 2  worktree riêng
 └─ worker 3  worktree riêng
        ↓
 kiểm ──→ merge

08 Hỏi đáp

Bốn câu hay hỏi

Tôi có cần biết code không?

Không. Cứ nói việc bằng tiếng Việt như ở mục 04; muốn tự xem thì mở desk.html.

Chọn nghề nào?

Không chắc thì chọn --universal. Gói này dùng được cho mọi việc: nghiên cứu, viết, lập kế hoạch, phân tích, học một thứ mới, làm hồ sơ, hay viết code. Chọn --ios nếu làm iOS. Chọn --designer nếu làm designer Figma.

Gỡ thế nào?

Chạy npx github:nguyennamkkb/agent-work-kit remove. File của bạn trở về đúng như trước khi cài. Thêm --purge-desk nếu muốn xoá cả bàn.

Cần Node bản nào?

Node 18 trở lên. Gõ node -v để xem. Thấy v18 hoặc cao hơn là được. Chưa có thì cài Node bản LTS trước, rồi làm lại bước cài.

Sẵn sàng đặt cái bàn vào dự án?

Một dòng lệnh, sáu bước, rồi cứ nói việc.
